# AlphaSketch

AlphaTastic's title font, made from the Hershey Fonts' Roman Simplex data (the `rowmans.jhf` file that
the MIT-licensed `hershey` npm package ships) by `scripts/buildTitleFont.mjs`.

The Hershey Fonts' distribution asks that these acknowledgements go with the font data:

- The Hershey Fonts were originally created by Dr. A. V. Hershey while working at the U. S. National
  Bureau of Standards.
- The format of the Font data in this distribution was originally created by James Hurt, Cognition, Inc.,
  900 Technology Park Drive, Billerica, MA 01821.
